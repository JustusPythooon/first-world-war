# Veröffentlichung über GitHub Pages

## Upload im Browser
- Repository bei GitHub erstellen.
- **Add file → Upload files** auswählen.
- Sämtliche Dateien und Ordner aus diesem Projekt hineinziehen.
- Commit-Nachricht `Initial release` eintragen und hochladen.
- **Settings → Pages → Deploy from a branch → main → /(root)** aktivieren.

## Wichtig
Die Datei `index.html` muss direkt im Hauptverzeichnis des Repositorys liegen. Groß- und Kleinschreibung bei Dateinamen wird auf GitHub Pages unterschieden.

## Fortschritt
Spielstände liegen nur im `localStorage` des jeweiligen Browsers und werden nicht zwischen Geräten synchronisiert.
